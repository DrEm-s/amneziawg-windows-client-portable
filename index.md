## Portable mode

Extract the archive and run `amneziawg.exe`. Persistent data is placed in `Data\` next to the executable.

> **Security warning:** tunnel configurations are stored as unencrypted `.conf` files and contain private keys. Keep the portable directory secure.

This is an unofficial community build based on the official [AmneziaWG Windows client](https://github.com/amnezia-vpn/amneziawg-windows-client).
